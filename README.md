**Автор:** Газизова Надежда Тимуровна

**Дисциплина:** Практикум по программированию 

## Описание проекта
Классическая игра Тетрис, реализованная на Python с использованием библиотеки `tkinter`. Включает вращение фигур, проверку коллизий, удаление заполненных линий и подсчет очков.

## Функциональные возможности
- 🟩 Появление случайных тетрамино (фигур)
- 🔄 Вращение фигур с проверкой границ
- ⬇️ Ускоренное падение и фиксация на поле
- 📊 Подсчет очков и уровней
- ⏹️ Окончание игры при заполнении стакана

## Требования к системе
- **Python:** 3.9 или выше
- **Библиотеки:** `tkinter` (встроена)

## Установка и запуск
1. Клонирование репозитория:
```bash
git clone https://github.com/murbyasha/tetris-project.git
cd tetris-project
```
2. Создание и активация виртуального окружения:
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```
3. Установка зависимостей:
```bash
pip install -r requirements.txt
```
4. Запуск программы:
```bash
python main.py
```
